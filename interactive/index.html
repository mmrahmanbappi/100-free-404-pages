Interactive 404 page templates

Pages with a small game or toy, so visitors smile before they leave. All 10 are free to download and use, and each one is a single HTML file.

  • Flashlight

    The page is dark. Move your mouse or finger to shine a light and find the way home.

    Live demoDownload

  • Catch the Page

    A button that runs away from the cursor. Visitors try to catch the missing page.

    Live demoDownload

  • Memory Cards

    A tiny memory game with six cards while visitors decide where to go next.

    Live demoDownload

  • Parallax

    Layers of shapes move at different speeds as you move the mouse, giving a sense of depth.

    Live demoDownload

  • Search Helper

    Suggests real pages as visitors type, using a small list you can edit in the file.

    Live demoDownload

  • Whack a Bug

    Little bugs pop up out of holes. Click them to fix the broken page.

    Live demoDownload

  • Fix the Number

    The 0 fell out of 404. Drag it back into place, or tap it, to fix the page.

    Live demoDownload

  • Button Masher

    A big button that counts clicks and says something new at each milestone.

    Live demoDownload

  • Choose a Path

    A signpost with three arrows pointing to real pages on the site.

    Live demoDownload

  • Snake

    A playable mini snake game. Use arrow keys or swipe to play.

    Live demoDownload

How to use one

Click Download to save the template as 404.html. Open it in any text editor, change the brand name, colors and links, then upload it to your site. The setup guide shows how to make your server use it for every missing page.
